# Sources of the bundled TeX files

## What this template is
*Nature Biotechnology* submission-format approximation built on the standard LaTeX `article` class
(12 pt, A4, single column) with Nature-style unnumbered sans-serif headings, `Fig. 1` captions
starting with a bold title sentence, and `naturemag.bst` superscript citations.

## Bundled files
* `naturemag.bst`: verbatim copy of the CTAN `nature` v1.0 bibliography style bundled in
  `templates/journal-npj-compmater/naturemag.bst` (LPPL, SHA-256 `fed4788763dedb10a3ba7f39612cf04e9e0aacd26265b006bb86371c563d2853`).
* Writing, translational framing, prose, figure, and Nature Portfolio preflight guidance in
  `venue.json` and `guidelines.md` is adapted from `Boom5426/Nature-Paper-Skills`
  (`nature-portfolio-playbook`, `scientific-prose-style`, `figure-style`, `submission-audit`).
