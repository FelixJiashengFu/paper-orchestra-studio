> 版本号说明：`v1.2.0` 是仓库与插件的版本。**桌面应用本身自 v0.1.0 起没有改动**，本页的桌面安装包只是重新构建，文件名仍是 `0.1.0`；已经装过 v0.1.0 桌面应用的不必重装。Python 后端包有更新，建议替换。

## 这一版新增

### 五平台插件，一份源码

- 五个平台的插件包都由 `plugins/shared/` 生成，内容一致：零依赖 Python MCP 服务（**24 个工具**、6 个资源、5 个提示词，含九标签工作台与工具树两个 MCP Apps 界面）、Studio 桌面桥接服务（**71 个工具**）和 **12 个工作流技能**。
- `plugins/scripts/verify_platforms.py` 一条命令做 44 项检查：比对清单、文件、技能与工具，并按各宿主的方式真实启动两个 MCP 服务核对握手结果。CI 在 Ubuntu、macOS、Windows 上各跑一遍。
- **Coder (coder.com) 工作区**：`plugins/coder/` 提供工作区安装脚本与模板片段。Coder 没有自己的插件格式，工作区里加载的仍是 Claude Code / Codex 的同一份插件包。

### 修回与投稿

- **`po_revision_toolkit`**（纯规则、不调用大模型）：审稿意见拆条成响应矩阵；投稿预检（页数/字数/摘要上限、占位符、未定义引用、双盲泄露、必备声明）；按 DOI 查 Crossref 撤稿与更正通告；CONSORT / PRISMA / STROBE / ARRIVE / ML 可复现性报告清单。
- **`po_reference_sync`**：Zotero（本地 Zotero 7 API 或 Web API）检索、入库、合并 BibTeX、导出 RIS；Overleaf git 关联、拉取与推送。推送默认只演练，需 `confirm_push=true` 才执行，且只做快进、从不删除文件。
- **5 个新技能**：`po-reviewer-response`（逐条回复信与 latexdiff 修订稿）、`po-venue-preflight`（选刊、防 desk reject 预检、压页、camera-ready、cover letter）、`po-claim-evidence-audit`（论断与证据台账、数字一致性、可复现性与数据/AI 使用声明）、`po-talk-poster`（论文转幻灯片、讲稿、问答演练、海报）、`po-submission-auditor`（端到端投稿审计）。

### Claude Code 侧边栏面板 `/po-pane`（v0.2.1）

- 在对话旁常驻显示 Studio 连接状态、项目、运行（费用 / Token / 阶段耗时 / 引文核查）、后台任务、文献库与环境检查。
- 「打开 PDF / 在文件夹中显示」支持 macOS、Windows、Linux 与 WSL。
- 侧边栏面板是 Claude Code 独有的扩展点；其余平台通过同样的工具和 MCP Apps 工作台获得同样的信息。

### 后端与插件工作台界面（自 v0.1.0）

- 写作与体检：Best-Paper 写作路由、结构化 AI 节奏与图表审计、摘要润色改动对照表、作者报告 `report.md`。
- LaTeX 助手：按行范围编辑、论断到引文的溯源。
- 插件内置的 MCP Apps 工作台：LaTeX / PDF 并排视图、内嵌 PDF 预览与双向 SyncTeX 高亮跳转（桌面应用原本就有这一功能）。

### 修复

- MCP 服务强制 UTF-8 标准输入输出，在 Windows 非 UTF-8 代码页下不再出错。
- `paper_writing_cli.sh` 统一为 LF 换行。
