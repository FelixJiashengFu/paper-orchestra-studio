PaperOrchestra Studio 的第一个安装版：本地 AI 科研论文流水线 + LaTeX 桌面工作台。

## 下载哪个文件

| 系统 | 桌面应用 | Python 后端（必装） |
| --- | --- | --- |
| Windows 10/11 | `PaperOrchestra-Studio_0.1.0_x64-setup.exe` | `PaperOrchestra-Backend-v0.1.0.zip` |
| macOS 11+（Intel / Apple 芯片） | `PaperOrchestra-Studio_0.1.0_universal.dmg` | `PaperOrchestra-Backend-v0.1.0.zip` |

可选：`paper-orchestra-studio-0.1.0-qoder.zip`（Qoder Desktop 插件）、`PaperOrchestra-LiveWorkbench-v0.1.0.zip`（浏览器实时论文工作台）。`SHA256SUMS.txt` 是校验值。

## 三步安装

1. 安装 **Python 3.11+** 和 **TeX**（Windows：MiKTeX 或 TeX Live；macOS：MacTeX）。
2. 解压 `PaperOrchestra-Backend-v0.1.0.zip`，运行安装脚本：
   - Windows：`powershell -ExecutionPolicy Bypass -File .\setup-backend.ps1`
   - macOS / Linux：`bash setup-backend.sh`
3. 安装桌面应用，打开后在「环境与算力」填入模型 API Key。

> 安装包暂未做代码签名。Windows 弹出 SmartScreen 时点「更多信息 → 仍要运行」；macOS 首次打开请右键 →「打开」。详见 [安装指南](https://github.com/FelixJiashengFu/paper-orchestra-studio/blob/main/docs/INSTALL.md)。

## 这一版包含

- 20+ 模型平台、19 步分任务模型路由，Token 用量与费用估算
- 8 源学术检索、离线与联网引文核查
- 19 套会议 / 期刊 / 中文 / 数模 LaTeX 模板，含中文稿件自动切换 XeLaTeX 编译
- SyncTeX 双向实时编辑器、论文体检、arXiv 投稿包、双盲检查、latexdiff、Overleaf 导出
- 科研工坊 6 大 SOP、文献库与知识图谱、科研绘图局部精修、Artifacts 阅读与导出
- 本地 Codex / 插件桥接：Qoder 插件与实时论文工作台可直接调用 Studio
