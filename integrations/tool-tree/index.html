回路 A · 后台作业

SOP、绘图、分析、技能和导出等任务返回 jobId，不能把“已提交”当成“已完成”。

后台工具 → jobId → job_status → succeeded / failed → 我汇报

回路 B · 论文流水线

写作运行由 Studio 持久化，通过 runId 追踪阶段、日志和最终产物。

start_run / resume_run → list_runs + get_run_logs → artifacts → 审核 / 修改

安全边界
